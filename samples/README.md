# Samples

Do not commit real movie clips or commercial videos.

Allowed:

- generated test patterns;
- tiny self-generated synthetic samples;
- links to public sample sources in docs;
- user-local media under `samples/media/`, which is ignored by git.

Never commit:

- `.mp4`
- `.mkv`
- `.mov`
- `.m4v`
- `.hevc`
- `.h265`
- `.av1`
