# v0.1.0 — HDR diagnostics lab baseline

This release note is prepared for the first public baseline release of `HDRVideoPlayer`.

## Release scope

Included baseline surfaces:

- Windows-first HDR / Dolby Vision local video player lab README;
- experimental macOS Swift Package scaffold documentation;
- validation matrix and legal / codec boundary documentation;
- public security policy and contribution guide;
- pull request template;
- existing build/test instructions.

## Validation before publishing

Windows:

```powershell
dotnet restore .\src\HDRVideoPlayer.App\HDRVideoPlayer.App.csproj
dotnet build .\src\HDRVideoPlayer.App\HDRVideoPlayer.App.csproj -c Debug
dotnet test .\tests\HDRVideoPlayer.Core.Tests\HDRVideoPlayer.Core.Tests.csproj -c Debug
```

macOS:

```bash
swift build --package-path macos/HDRVideoPlayerMac
swift test --package-path macos/HDRVideoPlayerMac
git diff --check
git status --short
```

Do not claim these commands passed unless their exact output is captured.

## Publishing path

After local `main` is synced to the validated remote HEAD:

```bash
git tag -a v0.1.0 -m "v0.1.0 — HDR diagnostics lab baseline"
git push origin v0.1.0
```

Manual release fallback:

```bash
gh release create v0.1.0 \
  --repo EthanSangSSS/HDRVideoPlayer \
  --title "v0.1.0 — HDR diagnostics lab baseline" \
  --notes-file docs/releases/v0.1.0.md \
  --verify-tag
```

## Honesty boundary

This release does not claim Dolby Vision certification, correct HDR presentation, complete platform parity, DRM bypass, or bundled codec support. It is an early diagnostics lab baseline.

## Known limitations

- System playback readiness does not prove HDR or Dolby Vision presentation accuracy.
- The macOS track is experimental and does not include a custom Metal renderer.
- No proprietary codecs, Dolby SDKs, or copyrighted sample media are bundled.
